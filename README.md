# little.space

A personal portfolio and digital garden. 

## About
This site is a collection of my professional experience, projects, and personal interests. It features an interactive travel map, a dynamic timeline, and a dark mode toggle.

## Built With
* HTML5
* CSS3 (Custom properties, Flexbox, CSS Grid)
* Vanilla JavaScript
* [Leaflet.js](https://leafletjs.com/) for the interactive map
* [TopoJSON](https://github.com/topojson/topojson-client) for map data parsing

## Features
* **Interactive Travel Map:** Highlights countries visited using GeoJSON data.
* **Collapsible Timeline:** Displays professional and educational milestones.
* **Responsive Design:** Optimized for mobile, tablet, and desktop.
* **Dark Mode:** Custom CSS variables for seamless theme switching.
